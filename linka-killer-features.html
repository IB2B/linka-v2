02Tier 0 — the three killer bets

These are not feature additions — they are positioning shifts. Build these and the pitch changes from "another scheduler" to "the social tool that runs itself."

01

AI Inbox Autopilot

Tier 0 Shipped

Layer autopilot on top of the inbox you just shipped — the way Yuma and Eclincher do for ecommerce.

  • Classify each DM/comment by intent (purchase, support, spam, complaint, FAQ) and sentiment.
  • Three response modes per rule: auto-reply, queue for approval, or flag-and-skip.
  • Train on the user's voice using the existing voice-analysis.ts pipeline.
  • Surface buying-signal DMs to the top, hide spam, auto-tag, auto-route to teammates.
  • Show "saved replies this week" and "$ pipeline surfaced" — make the value visible.
Why this wins

Sprout and Agorapulse charge $250+/mo for unified inbox; none have a true autopilot at the SMB tier. Buffer's engagement tool has no collision detection, no auto-routing, no advanced tagging. linka is already 60% there.

02

Viral Score & Hook Library

Tier 0 Shipped

The thing Tweet Hunter built a multi-million ARR business on. Two coupled features:

  • Pre-publish virality score — before "schedule," show 0–100 with reasons ("hook is weak," "no concrete number," "ends without CTA"). FeedHive does this and users love it.
  • Hook library — 500–2000 curated viral hooks per platform, filterable by niche/tone/format. One click rewrites the user's draft using that hook.
  • Tweet Hunter has 3M+ tweets indexed. linka doesn't need scale — 1,000 curated hooks beats 3M unsorted.
Why this wins

Turns a generic "AI generate" button into "AI that knows what works." This is the #1 reason creators pay $40/mo for Tweet Hunter or Hypefury.

03

Smart Recycler

Tier 0

FeedHive's secret weapon. The AI:

  • Scans generated_content + posting_history, ranks by engagement.
  • Picks evergreen winners and "underdog" posts (good content that flopped due to bad timing).
  • Auto-suggests rewrites so the resurface isn't literally the same post.
  • User sets cadence ("recycle 1/week per platform"); linka fills the calendar passively.
Why this wins

Solves the #1 user pain — "what do I post today?" — without any new content creation. Highest-leverage feature in the category. Users wake up, queue is full.

03Tier 1 — strong differentiators

Build these after Tier 0 lands. Each one is a credible chapter in the marketing site.

04

Video → Shorts repurposing

Tier 1

Drop in a YouTube/Loom/Zoom URL → AI extracts 5–10 short clips with captions, hooks, and per-clip virality scores. OpusClip and Vizard charge $20–60/mo for only this; bundling it inside a posting tool is a strong wedge. Vizard claims 92% accuracy on viral-moment detection.

05

Trend Radar & Idea Engine

Tier 1

Daily feed of trending topics in the user's niche (Tavily integration is already referenced) — plus 5 auto-generated post ideas riding each trend. Ocoya's Travis AI does this and it's one of their top retention features. Surfaces "post in the next 4 hours" urgency that beats generic "AI write a post."

06

Competitor tracking lite

Tier 1

Pick 5 competitor handles → daily digest: top post this week, hashtags they're using, post frequency, winning formats. Predis charges for this. Brandwatch charges $1,000+. A good-enough SMB version is a marketing weapon — every screenshot users share is free advertising.

07

Best-time-to-post (per audience)

Tier 1

Most tools show generic "Tuesday 2pm" charts. The killer version analyzes this user's actual followers' engagement on past posts and shows their personal best window per platform. Late API gives publish-time data; engagement comes from platform analytics endpoints.

08

Approval workflows & collision detection

Tier 1

For teams: comment-in-context on draft posts, role-based approval (USER drafts → ADMIN approves), inbox collision detection ("Sarah is replying to this DM"). This is Hootsuite and Buffer's biggest gap per user complaints. linka already has the role system — wiring it in is mostly UX.

06Strategic positioning

Competitors fall into three buckets. Each has a clear weakness linka can exploit.

BucketExamplesWeakness
Schedulers + AI bolted on Buffer, Later, Publer Shallow AI, weak inbox, no autopilot
Enterprise suites Hootsuite, Sprout Social, Sprinklr $250–1000/mo, bloated, slow to ship
AI-first creator tools Tweet Hunter, Typefully, Hypefury Single-platform (mostly X), no inbox, no team
linka's lane

AI-first, multi-platform, with the inbox and team features the creator tools lack — at SMB pricing. Position the product as "the social media tool that runs itself" — autopilot inbox, smart recycler, viral score, auto-replies. That is the headline. Everything else is supporting cast.

07Recommended sprint roadmap

Four sprints, 1–2 weeks each. No new vendors. Each one compounds on infrastructure already shipped.

SPRINT 1

Pre-publish virality score

Uses what you have — Anthropic + posts table. Highest-leverage starting point.

SPRINT 2

Smart Recycler

Reads posting_history, AI rewrites top performers, auto-fills calendar.

SPRINT 3

Inbox autopilot rules

Extends the inbox shipped today. Classify, route, auto-reply, queue for approval.

SPRINT 4

Hook library + 1-click rewrite

Curated 1,000-hook database, filterable, integrated into the generate flow.
